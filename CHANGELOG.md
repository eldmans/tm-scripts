## [v1.2.48] — 2026-09-04
### 🏷️ Разметка дубликатов при скачивании: `(старое_имя) DBL` и переменные шаблона
* **Именование дубликатов:**
  * Если скачивается файл, который уже был в базе, его имя формируется по правилу:
    `[новое_имя] ([старое_имя_без_расширения]) DBL.[расширение]`
  * Работает как с включённым шаблоном имени файла, так и без шаблона.
* **Переменные шаблона имени файла:**
  * `{dbl}`: автоматически подставляет ` (старое_имя) DBL` для дубликатов или пусто для новых файлов.
  * `{oldname}` / `{copy}`: подставляет имя исходного файла из базы без расширения.
* **Устранение старой нумерации:**
  * Убран старый счетчик дубликатов `(001)`, `(002)`, который вызывал странные префиксы в именах.
* **Файл перспективных идей `IDEAS.md`:**
  * Создан файл копилки идей для будущего развития функционала без захламления оперативного чата.

## [v1.2.47] — 2026-09-04
### ⚡ Ультра-оптимизация базы дубликатов (In-Memory O(1)), разделение Видео/Фото, чекбокс «Дубли» и фикс перелистывания
* **Молниеносный In-Memory кэш (`Set`/`Map`) на 18 000+ записей:**
  * При инициализации база вычитывается в оперативную память один раз (~1 МБ ОЗУ).
  * Поиск по хешу и URL происходит за 0.005 мс без ожидания транзакций IndexedDB.
* **Разделение базы на корзины (`video` / `photo`):**
  * Записи типизируются по расширению и контенту.
  * Видео сверяются с пулом видео, фото — с пулом фото, устраняя лишние проверки.
* **Чекбокс «Дубли» (`allowDuplicates`) в панели:**
  * Если включён: скрипт скачивает файл в любом случае без 6-секундной паузы, выводя информативный тост `⚠️ Дубликат: filename (дата)`.
  * Если выключен (по умолчанию): блокирует скачивание и выводит карточку с таймером 6 секунд для подтверждения повтора.
* **Исправление преждевременного перелистывания (`pdAction: +1`):**
  * Перелистывание слайда или удаление теперь происходит строго после фактического старта скачивания (`performPostDownloadAction`), а не по слепому таймеру.
  * При обнаружении дубликата перелистывание замораживается и ждёт подтверждения.
* **Автономный сканер генераций `scan_local_files.py`:**
  * Переменная `SCAN_FOLDER` вынесена наверх файла для редактирования в Блокноте.
  * Быстрый сбор метаданных, блочное вычисление SHA-256 с прогресс-баром и автоматическая отправка на GitHub в ветку `grok`.

## [v1.2.46] — 2026-09-04
### 🗄️ База данных истории скачиваний, дедупликация (SHA-256) и сканер файлов
* **Новый модуль `src/download/history.js` (IndexedDB + SHA-256):**
  * Полноценная локальная база данных на IndexedDB (`mossad_media_db`, хранилище `downloads`), не имеющая лимитов `localStorage`.
  * Вычисление криптографического хеша SHA-256 через нативный `crypto.subtle.digest` без сторонних библиотек.
  * Хранение хеша, имени файла, даты/времени скачивания, размера и ссылки на оригинальный пост.
* **Двухшаговое подтверждение скачивания дубликатов:**
  * При попытке повторного скачивания процесс блокируется.
  * Справа под виджетом (четвёртым блоком) появляется лаконичная Glassmorphic-карточка:
    * ⚠️ Уже скачивался
    * 📄 Имя файла
    * 📅 Дата и время
    * ⏱ Нажмите «Скачать» за 6с для повтора
  * При повторном нажатии «Скачать» (или хоткея `PageDown`) в течение 6 секунд файл скачивается.
* **Скрипт сканирования файлов на жестком диске (`scan_local_files.py`):**
  * Автономный Python-скрипт для потокового вычисления SHA-256 всех медиафайлов в заданной папке и подпапках.
  * Экспорт данных в файл `mossad_history_import.json`.
* **Кнопка «📥 База» в панели MOSSAD:**
  * Возможность загрузить `mossad_history_import.json` прямо в интерфейсе и мгновенно пополнить базу хешей.

## [v1.2.45] — 2026-09-04
### ⚡ Grok Hotkeys, Smart Actions & Universal Full Screen
* **Звук в плеере Grok (`ScrollLock` / `config.hk.sound`):**
  * Полноценная интеграция с DOM плеера Grok: программный клик по нативной кнопке звука вместо прямого мутирования `<video>`, исключающая рассинхронизацию UI плеера.
* **PageUp: Upscale / Повысить качество → 720p:**
  * Реализован двухшаговый выбор качества: нажатие «Upscale» / «Повысить качество» (напрямую или через 3 точки) с последующим авто-выбором «Увеличить до 720p» в подменю через серию попыток (100, 300, 500 мс).
  * Поддержка динамической настройки клавиши через `config.hk.upscale`, регистронезависимый поиск для RU и EN локализаций.
* **Скачивание и Удаление через кнопку «три точки» на Grok:**
  * При отсутствии прямой кнопки «Скачать» или «Удалить» на панели автоматически открывается меню «Действия с постом» и через тайминги (100, 300, 500 мс) нажимается нужный пункт.
* **Автоподтверждение удаления (`a.confirm`) и Удержание позиции (`hold post`):**
  * При удалении поста автоматически подтверждается модальное окно.
  * В режиме `hold post` скрипт вычисляет соседний пост и осуществляет плавный переход к нему, не позволяя Grok сбрасывать просмотр в самый конец ленты.
* **Универсальный авто-Full Screen (`FS`):**
  * Чекбокс `FS` вынесен в общую панель для всех поддерживаемых сайтов.
  * Функция `triggerUniversalFullScreen()` с серией из 3 попыток (100, 300, 500 мс) отрабатывает при перелистывании слайдов, смене URL и переходе после скачивания (`pdAction: 'up'`).
* **Универсальные хелперы `retryAction` и `triggerClick`:**
  * Вынесен общий движок повторных попыток `retryAction(fn, [100, 300, 500])` и метод клика `triggerClick(el)` в `src/core/utils.js`.
