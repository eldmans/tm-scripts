# CHANGELOG — Журнал изменений проекта MOSSAD

Все ключевые изменения, решения и обновления версий фиксируются здесь на понятном человеческом языке.

## [v1.3.23] — 2026-09-25
### ⌨️ Быстрое сохранение хоткеев для всех сайтов и новые умолчания клавиш
* **Глобальная синхронизация настроек горячих клавиш (`src/core/config.js`, `src/ui/panel.js`):**
  * Все настройки клавиш (`config.hk`) теперь автоматически сохраняются в глобальное хранилище Tampermonkey (`GM_setValue('mossad_hk_global')`) при любом закрытии модального окна настроек (кнопка «Закрыть», кнопка «💾 Сохранить и закрыть», клавиша `Escape`, закрытие через хоткей `Ctrl+F1`).
  * При открытии любой страницы и любого поддерживаемого сайта глобальные хоткеи автоматически подтягиваются через `GM_getValue`.
  * При переключении между вкладками браузера (`window.addEventListener('focus')`) хоткеи синхронизируются на лету без необходимости перезагрузки страницы.
  * В модальное окно настроек клавиш добавлен информационный баннер и кнопка немедленного сохранения: «💾 Сохранить» и «💾 Сохранить и закрыть».
* **Новые горячие клавиши по умолчанию:**
  * **PageDown** — Скачать (`download`).
  * **ArrowRight** (Стрелка вправо) — Следующий слайд (`nextSlide`).
  * **ArrowLeft** (Стрелка влево) — Предыдущий слайд (`prevSlide`).
  * Автоматическая миграция со старых настроек без потери пользовательских кастомных клавиш.
  * Обновлены подсказки в таблице настройки клавиш.

## [v1.3.22] — 2026-09-21
### ⚡ Автоматическая интеграция с Universal Prompt Vault
* **Связка MOSSAD с локальным сервером Prompt Vault (`http://127.0.0.1:5999`):**
  * Добавлена функция `sendPromptToVault(prompt, model, source, url)` в `src/core/utils.js`, отправляющая JSON на локальный сервис Prompt Vault.
  * В `src/engines/grok/helpers.js` промпт автоматически отправляется в базу `C:\AI\prompts\prompts.db`:
    1. При нажатии `Enter` в строке ввода промпта в Grok.
    2. При любом скачивании медиа (через хоткей или клик по нативной кнопке Download).
  * Вызов выполняется асинхронно и полностью бесшумно: при выключенном сервере скрипт не показывает никаких ошибок.

## [v1.3.20] — 2026-09-19
### 🏷️ Внедрение метаданных (промпт и ссылка) в медиафайлы Grok
* **Модуль инжектора метаданных (`src/download/metadata.js`):**
  * Создан универсальный бинарный инжектор метаданных для видео и изображений:
    * **MP4:** парсит атомы ISO BMFF / QuickTime, встраивает в `moov` блок `udta.meta.ilst` с атомами `©des` (промпт), `©cmt` («Prompt: ... URL: ...», читается в свойствах файла Проводника Windows), `purl` и `©url` (полная ссылка на пост). При расположении `moov` до `mdat` (faststart) автоматически корректирует смещения чанков в таблицах `stco` / `co64` на величину сдвига `delta`.
    * **JPEG:** встраивает маркер комментария COM (`0xFF, 0xFE`) и стандартный XMP APP1-пакет (`0xFF, 0xE1`, `http://ns.adobe.com/xap/1.0/`, `dc:description` и `dc:source`).
    * **PNG:** формирует и встраивает чанки `tEXt` (`Description`, `Comment`, `Source`, `prompt`, `parameters`) с расчетом CRC32.
    * **WebP:** встраивает чанк `XMP ` в RIFF-контейнер.
* **Интеграция с Grok (`src/engines/grok/helpers.js`):**
  * Добавлены хелперы `getGrokCurrentPrompt()` (извлечение промпта из textarea/contenteditable, alt-атрибута изображения, мета-тегов и скриптов) и `getGrokMedia()` (поиск прямого URL видео или полноразмерного фото).
  * `triggerGrokDownload()` переведён на прямую загрузку блоба, внедрение метаданных и сохранение через `saveBlobToDisk()`.
  * При невозможности прямой загрузки сохраняется надёжный фолбэк на клик нативной кнопки Grok.
  * Добавлен перехватчик клика по нативной кнопке скачивания Grok на странице: ручной клик по кнопке сайта также скачивает файл со встроенными метаданными.
* **Координация с автоскачиванием в слайдшоу (`src/slideshow/engine.js`, `src/download/router.js`):**
  * В `triggerNextSlide()` автоскачивание в обоих слайдшоу (малом и большом) теперь ожидает завершения сохранения файла перед переходом на следующий пост, предотвращая обрыв сетевого запроса при выгрузке страницы.

## [v1.3.17] — 2026-09-18
### 🏷️ Шаблон сохранения на Grok: `{conv4}-{id4}-{domain}.{ext}` и динамическая длина переменных
* **Новый дефолтный шаблон для Grok (`src/core/utils.js`, `src/core/config.js`, `src/engines/grok/helpers.js`, `src/download/router.js`):**
  * Для `grok.com` дефолтный шаблон имени файла изменён с `{id8}-{domain}.{ext}` на `{conv4}-{id4}-{domain}.{ext}`.
  * Пример: страница `https://grok.com/imagine/post/403982b7-f296-4080-b3a6-f9f708ae1ee6?conversation=d03e317d-3de3-40f3-85e7-7d739213b7ce` сохраняет файл как `d03e-4039-grok.mp4`.
* **Динамическая длина переменных хешей и ID:**
  * Синтаксис шаблона теперь поддерживает указание произвольной длины среза: `{convN}` / `{conv[N]}` (например, `{conv4}`, `{conv8}`, `{conv}`) и `{idN}` / `{id[N]}` (например, `{id4}`, `{id8}`, `{id}`).
  * Синонимы: `{conversation}` -> `conv`, `{uuid}` / `{hash}` / `{postid}` -> `id`, `{user}` / `{author}` -> `username`.
* **Надёжное извлечение Conversation ID:**
  * Скрипт извлекает `convId` из параметра query string (`?conversation=...` или `?conv=...`), а при его отсутствии в URL — из сохранённой коллекции в `sessionStorage` (`grok_gallery_collection`) или ссылок DOM.
  * Если `convId` отсутствует, скрипт автоматически очищает висячие и ведущие дефисы, формируя аккуратное имя `4039-grok.mp4` без префикса `-`.
* **Централизованный рендеринг шаблонов (`src/core/utils.js`):**
  * Введена единая функция `renderFilenameTemplate(rawTpl, vars, isDup, dblSuffix, defaultExt)`, гарантирующая единообразие именования файлов во всех модулях и движках.
* **Обновление интерфейса настроек (`src/ui/panel.js`):**
  * В плейсхолдер и подсказку поля «Шаблон» добавлены переменные `{conv4}` и `{id4}`.
* **Автоматическая миграция конфига (`src/core/config.js`):**
  * Для пользователей на `grok.com`, у которых был сохранён старый дефолтный шаблон `{id8}-{domain}.{ext}`, шаблон автоматически обновляется до `{conv4}-{id4}-{domain}.{ext}`.
