# CHANGELOG — Журнал изменений проекта MOSSAD

Все ключевые изменения, решения и обновления версий фиксируются здесь на понятном человеческом языке.

## [v1.2.44] — 2026-09-04
### 🚀 Архитектурная революция (Модульность)
* **Распил монолита на модули в `src/`:**
  * Файл `mossad.user.js` (2700 строк) больше не редактируется руками.
  * Исходники разнесены по изолированным файлам в `src/` (`core/`, `engines/`, `download/`, `slideshow/`, `ui/`).
  * Каждый сайт (Grok, Pinterest, Instagram, Noodle) теперь живет в отдельном компактном файле в `src/engines/`.
* **Сборщик `build.py`:**
  * Автоматически собирает модули в итоговый `mossad.user.js` за доли секунды.
  * Проверяет целостность UTF-8 и эмодзи (`❌`, `✅`, `🖼`, `📹`, `💾`).
  * Флаг `--bump` автоматически повышает патч-версию во всех местах (`banner.js`, `domain.js`, футер `panel.js`).
* **База знаний и граблей:**
  * Создан файл `ANTI_PATTERNS.md` («Кладбище неудачных гипотез») — сборник всех граблей по Grok, Instagram, Pinterest и кодировкам.
  * Обновлены `START_HERE.md` и `MODPLAN.md` под модульную структуру.
  * Создан `.gitignore`, весь мусор из корня перемещен в `_archive/`.
* **Безопасность:**
  * В ветку `backup-v1.2.43-monolith` и тег `v1.2.43-pre-modularization` на GitHub выгружен полный снимок проекта до распила.
