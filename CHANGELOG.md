# CHANGELOG — Журнал изменений проекта MOSSAD

Все ключевые изменения, решения и обновления версий фиксируются здесь на понятном человеческом языке.

## [v1.3.4] — 2026-09-10
### 🎬 Бесшовный переход hold post через киноплёнку без перезагрузки страниц
* **Интеграция Filmstrip в механизм удержания поста (`hold post` / `src/engines/grok/delete.js`):**
  * Ранее при удалении видео с включённой опцией `hold post` скрипт выполнял жесткий переход `window.location.href = finalTargetUrl`, что приводило к полной перезагрузке страницы в браузере.
  * Теперь целевой следующий кадр определяется непосредственно по кнопкам киноплёнки `[data-filmstrip-item="true"]` на основе активного класса (`ring-white`) или совпадения UUID в пути ассета (`generated/<uuid>/`).
  * После подтверждения удаления скрипт программно кликает по следующей кнопке киноплёнки (`items[nextIdx].click()`).
  * В результате Grok нативно обновляет плеер и переключает воспроизведение на следующий кадр **без перезагрузки страницы** — плавно обновляется только видео и URL в адресной строке (`history.replaceState`).
  * Устранены холостые клавиатурные шаги «вперёд-назад» со стрелками при наличии киноплёнки.
* **Синхронизация и отказоустойчивость:**
  * Улучшена функция `grokGetActiveFilmstripIndex` в `src/engines/grok/helpers.js` с поддержкой поиска кадра по совпадению `generated/<uuid>/` с текущим путем страницы.
  * В `grokStepFilmstrip` добавлен циклический переход (`% items.length`) при достижении границы ленты кадров.
  * Сохранены все резервные пути (SPA-роутер `grokSpaNavigate` и соседние посты из коллекции для одиночных генераций).

## [v1.3.3] — 2026-09-09
### 📋 Монолитное скрепление списка с меню и динамическая подсветка активного файла
* **Монолитное скрепление плейлиста с меню виджета (`src/engines/grok/ui-playlist.js`):**
  * Панель списка (`#mossad-playlist-panel`) теперь монтируется непосредственно внутрь корневого контейнера виджета `#mossad-widget-container` над панелью настроек, а не висит отдельным окном в `document.body` с фиксированными координатами.
  * Список оформлен в едином Glassmorphism-стиле виджета (совпадающая ширина, радиусы, размытие `backdrop-filter: blur(16px)` и тени).
  * При перетаскивании меню за верхнюю полосу, полосу галереи или шапку списка весь виджет перемещается как единый монолитный блок.
  * Шапка списка сделана липкой (`sticky top: 0`) и поддерживает перетаскивание (`window.makeWidgetDraggable`).
  * Состояние открытия списка сохраняется в `sessionStorage` (`mossad_playlist_open`) и автоматически восстанавливается при перезагрузках страницы или межпостовых переходах.
* **Динамическая подсветка активного файла при воспроизведении:**
  * Добавлена функция `grokHighlightActivePlaylistItem`, сопоставляющая текущий UUID генерации или URL с элементами открытого списка.
  * Активный файл ярко выделяется: акцентный синий фон (`rgba(59, 130, 246, 0.28)`), светящаяся рамка (`border: 1px solid rgba(96, 165, 250, 0.6)`), контрастный белый жирный текст и префикс `▶ `.
  * Если активный файл находится внутри сгруппированного блока, заголовок и контур группы также подсвечиваются акцентным синим цветом.
  * Автоматический плавный скроллинг (`scrollIntoView({ block: 'nearest', behavior: 'smooth' })`) удерживает играющий файл в поле зрения при листании длинных списков.
* **Интеграция с движком большого слайдшоу (`slideshow.js`, `helpers.js`, `ui-bar.js`):**
  * Запуск большого слайдшоу (по кнопке «🎲 Слайдшоу» или клику на элемент списка) автоматически открывает список и подсвечивает текущий кадр.
  * Клик по элементу списка больше не закрывает окно (`panel.remove()` убран), а плавно переключает воспроизведение и обновляет подсветку.
  * Подсветка синхронизируется на каждом тике слайдшоу, при переходах внутри киноплёнки (filmstrip), кликах и клавиатурной навигации стрелками.

## [v1.2.51] — 2026-09-05
### 🔁 Кнопка «R» в центре D-pad и циклический повтор плейлиста ленты
* **Кнопка `R` (Repeat / Loop Playlist) в центре крестовины D-pad:**
  * D-pad перестроен в эргономичную сетку 3x3: вверху `▲`, внизу `▼`, слева `◀`, справа `▶`, в центре — кнопка `R`.
  * При клике на `R` переключается режим циклического повтора ленты (`config.loopFeed`), кнопка подсвечивается зелёным цветом.
* **3-ступенчатый детектор окончания ленты (0с -> 1с -> 3с):**
  * При перелистывании скрипт делает исходную попытку.
  * Если через 1 секунду URL не изменился, делает 2-ю попытку.
  * Если через 3 секунды (на 4-й секунде суммарно) URL по-прежнему не изменился, делает 3-ю попытку.
  * Если URL не изменился и после 3-й попытки — фиксируется достижение конца ленты.
* **Автоматическая перемотка на начало при конце ленты:**
  * Если режим `R` включён: автоматически запускается перемотка в противоположную сторону до самого начала, после чего слайдшоу непрерывно продолжается со старта ленты.
  * Если режим `R` выключен: слайдшоу аккуратно останавливается с уведомлением «⏹ Конец ленты».

  * Если включён: скрипт скачивает файл в любом случае без 6-секундной паузы, выводя информативный тост `⚠️ Дубликат: filename (дата)`.

  * Переменная `SCAN_FOLDER` вынесена наверх файла для редактирования в Блокноте.
