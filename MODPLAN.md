## 🚀 Как работать «команде программистов»

1. **Задача по конкретному сайту (например, Grok):**
   * Открываем **только** `src/engines/grok.js` (~500 строк вместо 2700).
   * Контекст не сгорает, чужие модули гарантированно не задеты.
2. **Задача по настройкам:**
   * Открываем `src/core/config.js` или `src/ui/panel.js`.
3. **После правок:**
   * Выполняем `python build.py` (или `python build.py --bump` при выпуске релиза).
   * Проверяем, что сборщик выдал `BUILD SUCCESS` и `OK` по эмодзи.
   * `git add .` -> `git commit -m "..."` -> `git push origin grok`.
