## ⚡ Протокол автономной работы следующей модели (Autonomous Loop Protocol)

Следующая модель, открыв новый чат с этим хендоффом, работает **в бесконечном автономном цикле** по следующим строгим правилам:

1. **Глобальный часовой таймер (Watchdog):**
   * Сразу при старте ставит таймер на 1 час (`schedule DurationSeconds: 3600` с промптом: *"Часовой аудит: проверить, идёт ли работа над проектом MOSSAD. Если работа идёт — поставить следующий таймер на 1 час"*).
   * Этот часовой таймер работает как внешний сторож прогресса на протяжении всей жизни задачи.

2. **Квантование задач:**
   * Модель берет из данного списка **ровно один адекватный законченный кусок задачи** (этап).
   * Выполняет его качественно, без спешки, соблюдая строгие правила версионирования (`GEMINI.md`: обязательный бамп версии `python build.py --bump`, лог, футер окна настроек, проверка `python build.py --verify`, git commit & push).

3. **Завершение этапа — Мелодия хита:**
   * По завершении каждого этапа скрипт/агент воспроизводит короткую мелодию (5–6 узнаваемых нот) мировых суперхитов (случайный выбор из списка):
     * *Титаник* (My Heart Will Go On: `F4 - G4 - G4 - A4 - G4 - F4`)
     * *Терминатор* (Главная тема / пульсация / стаккато)
     * *Звёздные войны* (Имперский марш: `G4 - G4 - G4 - Eb4 - Bb4 - G4`)
     * *Крёстный отец* (Speak Softly, Love)
     * *Миссия невыполнима* (Такт 5/4)
     * *Джеймс Бонд 007* (Характерный полутоновый мотив)
     * *The Good, the Bad and the Ugly* (Ковбойский свист / мотив Морриконе)
   * Мелодия воспроизводится через встроенный аудио-модуль MOSSAD (`beeps.js` / Web Audio API) либо тестовый звуковой сигнал.

4. **Пятиминутная пауза ожидания (5-min Timer):**
   * Сразу после воспроизведения мелодии агент ставит таймер на 5 минут (`schedule DurationSeconds: 300`).
   * В течение этих 5 минут пользователь может проверить работу, внести коррективы или остановить процесс.
   * Если за 5 минут указаний от пользователя не поступило и таймер сработал — агент **автоматически берет следующий этап из списка и продолжает работу**.

5. **Бесконечность процесса:**
   * Процесс продолжается непрерывно, пока все задачи из хендоффа не будут выполнены, либо пока не вмешается пользователь («пока на планете Земля есть электричество или пока не выключили Windows»).

## 🛠 Технический регламент выполнения задач (Правила для агента)

1. **Версионирование (`GEMINI.md`):**
   * Перед любым коммитом обязателен инкремент версии:
     * Шапка юзерскрипта (`// @version X.X.X`)
     * Лог старта в консоли (`console.log('[MOSSAD vX.X.X]...')`)
     * Футер окна настроек (`vX.X.X · YYYY-MM-DD`)
   * В текстовом ответе обязательно называть текущую версию.

2. **Сборка и валидация:**
   * Сборка строго через `python build.py`. Ручные правки `mossad.user.js` категорически запрещены.
   * Проверка через `python build.py --verify`.
   * Git фиксация: `git add .`, `git commit -m "vX.X.X: ..."`, `git push origin grok`.

3. **Защита от изобретения велосипеда:**
   * Перед написанием нового функционала перепроверять уже существующие функции в `src/core/`, `src/download/`, `src/ui/`. Если функционал есть — развивать и объединять, а не дублировать.
