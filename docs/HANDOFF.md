## 1. Что это за проект

**MOSSAD** (Media Objects Slideshow and Download) — один юзерскрипт Tampermonkey (`mossad.user.js`) для медиа-сайтов:
авто-слайдшоу, скачивание (в т.ч. видео со звуком с Pinterest), горячие клавиши (свои для каждого сайта и общие),
модули под конкретные сайты: **Grok Imagine** (главный), Pinterest, Instagram, RedGifs, NoodleMagazine, Civitai, VKVideo.
С v1.3.66–1.3.67 есть **лёгкий слой на всех сайтах**: DND-скачивание (Ctrl+клик / Ctrl+правый клик) и управление скоростью видео
(замена расширения «Speed Control»).

Установка для владельца: <https://raw.githubusercontent.com/eldmans/tm-scripts/grok/mossad.user.js>.
Браузеры владельца: **Firefox и Edge** (Tampermonkey).

## 2. Архитектура

* **Исходники — `src/`, бандл `mossad.user.js` генерируется `build.py`.** Руками бандл не править никогда.
* `build.py` склеивает модули в один файл:
  * `GATE_MODULES` — выполняются на любой странице: `src/light/*` (DND, скорость видео, их UI) и `src/core/domain.js` (проверка сайта, команда меню Tampermonkey).
  * `MODULES` — всё остальное, обёрнуто в `function mossadMain() { … } // /mossadMain`, вызывается только на сайтах из списка (встроенные + GM `mossad_sites`, вкладка «🌍 Сайты»).
  * С v1.3.54 бандл сжимается встроенным мини-лексером (без комментариев и отступов), самопроверка токенов 1:1. Грабли — ANTI_PATTERNS §33.
  * `// @noframes` (v1.3.58): во фреймах скрипт не запускается.
* Папки:
  * `src/core/` — `boot.js`, `config.js` (настройки и умолчания), `domain.js`, `hotkeys.js`, `sync.js` (GitHub-синхронизация конфига; токен в GM, не в localStorage), `utils.js`.
  * `src/engines/` — сайты: `grok/` (много модулей: `helpers`, `media`, `download`, `filmstrip`, `video-gen`, `slideshow`, `queue`, `prompt-cycle.js` (цикл «\»), `key-guard.js` (клавиши, которые не кидают в промт) и др.), `pinterest.js`, `pinterest-keys.js`, `instagram.js`, `redgifs.js`, `noodle.js`.
  * `src/download/` — перехват медиа, роутер, история/дубликаты, метаданные, blob.
  * `src/slideshow/engine.js` — таймеры и шаги слайдшоу.
  * `src/ui/` — панель, окно настроек (`settings-modal.js`), подписи (`labels.js`), сайты, тудушки, окно тегов шаблона (`tpl-help.js`).
  * `src/light/` — `dnd.js`, `speed.js`, `ui.js`.
* Все модули — в одной области видимости (простая склейка). **Пространства имён (`MOSSAD.grok.*`) пока не вводились** — ANTI_PATTERNS §15.

## 3. Сборка и тесты

```bash
python build.py            # собрать mossad.user.js из src/
python build.py --bump     # +1 к версии (шапка @version, лог при старте, футер окна настроек с датой)
python build.py --verify   # бандл == сборка из src/ + node --check (то же делает CI)
```

**CI** — GitHub Actions `build-verify` (`.github/workflows/build-verify.yml`) на каждый push/PR в `grok`:
`build.py --verify`, `node --check mossad.user.js`, сравнение AST сжатого и несжатого бандла (`tools/check_strip.js`, acorn).

**jsdom-тесты** — `tests/` (перенесены из рабочих заметок агента; в CI не входят):

```bash
cd tests
npm install          # ставит jsdom
node run_all.js      # все *_test.js по очереди; node run_all.js v169 — только подходящие по имени
```

* Харнессы: `ss_harness.js` (общая загрузка бандла в jsdom с фейковыми GM_* и лентой Grok), `light_harness.js` (лёгкий слой).
* Тест по умолчанию читает `../mossad.user.js`; другой бандл — переменная `BUNDLE_SRC` (или `BUNDLE` для `ss_harness`).
* Многие тесты временно вставляют в бандл экспорт (`window.__P = {…}`) перед `} // /mossadMain` и пишут `.bundle_vNNN.js` рядом (в `.gitignore`).
* `ss_tests.js` — старый набор слайдшоу (v1.3.38), запускается отдельно: `node ss_tests.js`.
* Состояние на 2026-10-21: **34 из 34 `*_test.js` проходят** на v1.3.69.

## 4. Правила репозитория (обязательно)

1. Правка только в `src/` → `python build.py` → при любом изменении поведения `python build.py --bump` → `python build.py --verify`.
2. **Каждая правка — новая версия** (GEMINI.md §1), запись в `CHANGELOG.md` (по-русски: «Было / Стало», файлы, откат, тесты).
3. Коммиты прямо в ветку `grok`, `git push origin grok`, проверить, что CI зелёный.
4. Перед задачей читать `ANTI_PATTERNS.md`; неудачные гипотезы и грабли — дописывать туда.
5. В ответе владельцу всегда указывать номер текущей версии.
6. Не ломать единый UI (glassmorphism, верхняя плашка, панель).

## 5. Предпочтения владельца (eldmans)

* Общение **только по-русски**. Владелец — мужчина: обращаться к нему в мужском роде; о себе (агенте) — тоже в мужском роде.
* Работать осторожно: объяснять, что собираешься сделать, и ждать подтверждения перед крупными изменениями.
* **Поэтапно:** каждая доработка — отдельная версия с записью в CHANGELOG, чтобы можно было откатиться к версии, где сломалось.
* **Лёгкость:** скрипт грузится на каждой вкладке — минимум работы на чужих сайтах, без лишних слушателей/таймеров, режим «Выкл» должен реально ничего не запускать.
* Настройки — простые: текстовые поля через запятую, которые можно править руками; окна «?» со списком, где клик вставляет значение в поле.
* Горячие клавиши должны быть уникальны (предупреждение «занята: …», Да — у старого действия клавиша очищается); дубликаты подсвечиваются красным, автоматически не чистятся.
* Grok: соотношение сторон — только у поля промта (в правой панели выбор сразу перегенерирует — нельзя). Пункт «бот» в цикле «\» не нужен. Клавишу «\» владелец в текстах не использует — её можно перехватывать везде.
* Pinterest: фокус на пин как у Tab, без своих рамок и подписей; открытие — штатный Пробел.
* Скорость видео: клавиши как в старом Speed Control (W, E, Z, X, R, G, V, C), меняется только текущее видео, клавиши не должны кидать фокус в промт Grok.
* `{date}` в шаблоне имени есть, но в шаблоны по умолчанию не добавляется.

## 8. Что ждём от владельца (команды для консоли / логи)

1. **Если цикл «\» или ↑/↓ в Grok ведут себя не так** — на странице Grok Imagine с видимым полем промта открыть консоль (F12) и выполнить, затем прислать скопированный текст:

   ```js
   (() => { const ta = document.querySelector('textarea, [contenteditable="true"]'); let c = ta; for (let i = 0; c && i < 6 && c.tagName !== 'FORM'; i++) c = c.parentElement; copy((c || document.body).outerHTML.slice(0, 200000)); console.log('Скопировано: DOM композера'); })();
   ```
   (и строки `[MOSSAD] grokCycle: …` из консоли, если они есть).
2. **Если страница Grok тормозит после повторов круга слайдшоу** — включить F1 → «Debug-лог слайдшоу», дождаться тормозов, затем F1 → «📋 лог» и прислать (рост `videos`/`nodes` от круга к кругу — накопление на стороне сайта).
3. Отзыв по живой работе v1.3.62 (звук Pinterest) и v1.3.66–1.3.67 (DND, скорость видео) в Firefox и Edge.

## 10. Как продолжить (для нового агента)

1. `git clone https://github.com/eldmans/tm-scripts && cd tm-scripts && git checkout grok`.
2. Прочитать по порядку: этот файл → `START_HERE.md` → `GEMINI.md` → `ANTI_PATTERNS.md` → верх `CHANGELOG.md`.
3. `python build.py --verify` и `cd tests && npm install && node run_all.js` — убедиться, что всё зелёное.
4. Спросить владельца (по-русски), что из раздела 8 он уже проверил и что брать следующим из раздела 9.
5. Каждую доработку — отдельной версией: правка в `src/` → тест в `tests/vNNN_test.js` → `build.py --bump` → запись в CHANGELOG → `--verify` → commit/push в `grok` → проверить CI.
