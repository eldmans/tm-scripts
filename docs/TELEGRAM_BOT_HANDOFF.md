## 🛠️ 2. Реализованный функционал (v2.0)

### 1. 🎤 Двухдвижковое распознавание голосовых сообщений (STT):
- **Основной движок:** Google Speech Recognition API (`speech_recognition`) через конвертацию аудио в WAV — скорость обработки ~1 сек, высокая точность русского языка.
- **Оффлайн-резерв:** `faster-whisper` с тяжелой моделью `large-v3-turbo` (кэширована локально в `.cache\huggingface\hub\models--mobiuslabsgmbh--faster-whisper-large-v3-turbo`), 14 потоков, понимает мат, сленг, знаки препинания и акценты.
- **Интерактивное всплывающее окно:**
  - При получении голосового бот присылает уведомление:  
    `🎤 Ваше голосовое сообщение распознано`
  - Под ним инлайн-кнопка: **`[📝 Просмотреть текст]`**.
  - Нажатие открывает нативное всплывающее модальное окно Telegram (`show_alert=True`) с точным текстом того, что надиктовано.

### 2. 🎧 Железный формат ответов (для улицы и наушников):
Любой ответ от системы отправляется по строгому регламенту:
1. **Первая строчка:** Короткий статус в 1-2 строки (например: `✅ [MOSSAD v1.4.24] Задача принята: Починить плеер`).
2. **Следом — готовое аудио:** Голосовой файл (Telegram Opus OGG), синтезированный компом через `Microsoft Irina Desktop`. Владелец на ходу в наушниках сразу жмёт Play.
3. **Инлайн-кнопки:**
   - **`[📖 Подробнее]`** — по клику открывает полный текст задачи, отчёта или логов (до 180 символов — во всплывающем модальном окне, больше — разворачивает полный текст в чат).
   - **`[🎧 Повторить аудио]`** — повторный синтез и отправка голоса.

### 3. 🎯 Двусторонний диалог с 3 сущностями:
- 🤖 **Telegram-инженер** (`tg_engineer`) — технический мониторинг моста, состояние ПК, загрузка, скриншоты, лимиты, настройки бота.
- 🍅 **Координатор MOSSAD** (`mossad`) — приём задач по юзерскрипту, багрепорты, контроль версий, отправка сигнала пробуждения `wake_signal.txt`.
- 🧠 **Голова Эльдара** (`eldar`) — фильтр эргономики («управление с дивана», «ноль лишних кликов», «никаких выпадающих списков»), банк концептуальных мыслей в `inbox_eldar.txt`.

### 4. 📊 Двойной учёт лимитов Antigravity:
- **5-часовой скользящий лимит:** процент, прогресс-бар `██████░░░░`, оставшееся время до сброса.
- **Недельный лимит:** процент, прогресс-бар, оставшееся время до сброса и дата.
- **Ступенчатые алерты:** при пробитии порогов 75% → 50% → 25% → 15% → 10% → 5% бот шлёт текстовый и голосовой алерт.
- **Аварийный авто-тормоз:** при падении любого из лимитов до `<= 5%` создаётся `stop_signal.txt`, останавливающий всех автономных агентов на ПК.

## 🚀 Управление процессом на ПК

- **Запуск:** двойной клик по `START_BOT.bat`. Скрипт проверяет и завершает зависшие копии, после чего стартует чистый процесс.
- **Остановка:** двойной клик по `STOP_BOT.bat` или кнопка в боте «🛑 Выключить бота на ПК» с двойным подтверждением.
