# archive/ — устаревшие standalone-скрипты

Эти юзерскрипты заменены единым **MOSSAD** (`mossad.user.js` в корне репозитория) и больше не развиваются.
Хранятся только для истории (перенесены сюда `git mv` в 2026-10-19, содержимое не менялось).

| Файл | Что это |
|---|---|
| `grok-hotkeys.user.js` | Ранние хоткеи Grok |
| `grok-hotkeys-slideshow.user.js` | Хоткеи + слайдшоу Grok (ранняя версия) |
| `grok_hotkeys_plus_slideshow.user.js` | Хоткеи + слайдшоу Grok (последняя версия до MOSSAD) |
| `universal_media_enhancer.user.js` | Универсальный улучшатель медиа (до MOSSAD) |

⚠️ Их `@updateURL`/`@downloadURL` указывают на старые пути в корне — у тех, у кого они ещё установлены,
автообновление перестанет работать. Установите MOSSAD:
https://raw.githubusercontent.com/eldmans/tm-scripts/grok/mossad.user.js
