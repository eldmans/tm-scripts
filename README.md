# Grok Hotkeys + Slideshow

> Единый мощный userscript для Grok: все основные горячие клавиши + умное автолистание слайдов + настройка клавиш прямо в браузере.

**Версия:** 4.0  
**Автообновление:** Включено

---

## ✨ Возможности

### Глобальные хоткеи (работают везде)

| Клавиша (по умолчанию)     | Действие                                              |
|---------------------------|-------------------------------------------------------|
| `PageDown`                | Скачать изображение/видео                             |
| `PageUp`                  | Улучшить качество / Upscale                           |
| `Ctrl` + `Delete`         | Удалить видео                                         |
| `ScrollLock`              | Включить/выключить звук                               |
| `Pause/Break`             | Play / Pause видео                                    |
| `Home`                    | Открыть сохранённые генерации                         |
| `Ctrl` + `Home`           | Открыть сохранённые генерации (новая вкладка)         |
| `F1`                      | Справка / Настройка клавиш                            |

### Только на страницах `/imagine/post/*`

| Клавиша (по умолчанию) | Действие                          |
|-----------------------|-----------------------------------|
| `Insert`              | Показать/скрыть панель слайдшоу   |
| `F8`                  | Lag Monitor                       |

### Автолистание слайдов
- Нажми **`Insert`** — покажется панель управления.
- Кнопка с числом (7 или 13) — запускает/останавливает автолистание.
- `+` / `−` — изменить интервал (3–60 сек), пресеты `7` и `13` слева.
- Галочка **↓** — автоматически скачивать каждый слайд.

## ⌨️ Настройка клавиш

Нажмите **`F1`** чтобы открыть окно справки/настроек:

1. Кликните на любую клавишу в списке — она подсветится синим.
2. Нажмите новую клавишу или комбинацию (`Ctrl+K`, `Alt+F`, и т.д.).
3. При конфликте скрипт предложит выбор: переназначить (старое действие уйдёт на дефолт или очистится) или отменить.
4. Кнопка **«Сбросить к значениям по умолчанию»** — восстанавливает все клавиши.

> **Ограничение:** Клавиша для «Справки / Настроек» может быть только `F1`, `F2`, `F3` или `F4` (без модификаторов). Это сделано чтобы не потерять доступ к настройкам.

Конфиг сохраняется в `localStorage` браузера под ключом `grok_hotkeys_config`.

## 📝 Примечания

- Скрипт определяет страницу автоматически — панель слайдшоу и Lag Monitor доступны только на `/imagine/post/*`.
- `Insert` работает как toggle (показать/скрыть).
- Все остальные хоткеи работают глобально на всём сайте grok.com.
- Комбинации с `Ctrl+W`, `Ctrl+T` и подобными браузер перехватит раньше скрипта — лучше их не использовать.
