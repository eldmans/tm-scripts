# MOSSAD (Media Objects Slideshow and Download)

🇺🇸 **English** | 🇷🇺 **Русский** (ниже)

MOSSAD is a universal userscript that combines powerful media features into one single tool: automated slideshows, hotkey management, downloading (including Pinterest `expMp4` audio extraction), and site-specific enhancements (Grok, Civitai, RedGifs, VKVideo, NoodleMagazine). 

It replaces the older `grok_hotkeys_plus_slideshow` and `universal_media_enhancer` scripts.

## ✨ Features
- **Universal Glassmorphism UI**: A sleek top bar with a timer, start button, settings dropdown, and download button.
- **Auto Slideshow**: 
  - Tracks video loops via `requestAnimationFrame` for extreme accuracy.
  - Custom delays for photos and pauses after videos.
  - Multi-directional D-Pad support for navigation.
- **Smart Downloads**: 
  - Unified 💾 button for downloading media.
  - Extracts raw MP4 streams with audio (`expMp4`) from Pinterest.
  - Configurable post-download actions (e.g., download and auto-delete on Grok).
- **Per-Domain Settings**: Settings are saved locally per root domain. What happens on Grok stays on Grok.
- **NoodleMagazine Enhancer**: Expands video to 100% width and hides "Join Now" popups automatically.
- **Customizable Hotkeys**: Rebind any action via F1.

🇷🇺 **Русский**

MOSSAD — это универсальный юзерскрипт, объединяющий все возможности для работы с медиа: авто-слайдшоу, управление горячими клавишами, скачивание (включая извлечение аудио+видео с Pinterest) и модули для конкретных сайтов (Grok, Civitai, RedGifs, VKVideo, NoodleMagazine).

Он заменяет старые скрипты `grok_hotkeys_plus_slideshow` и `universal_media_enhancer`.

## ✨ Возможности
- **Единый стеклянный UI (Glassmorphism)**: Компактная верхняя панель с таймером, кнопкой "Пуск", меню настроек и кнопкой скачивания.
- **Авто-слайдшоу**:
  - Отслеживание циклов видео через `requestAnimationFrame` для максимальной точности.
  - Настраиваемые задержки для фото и паузы после завершения видео.
  - Навигация (D-Pad) в любом направлении.
- **Умное скачивание**:
  - Единая кнопка 💾 для скачивания любого медиа.
  - Скачивание видео **со звуком** (формат `expMp4`) с Pinterest, минуя заглушки blob.
  - Действия после скачивания (например, перелистнуть на +1 или удалить пост на Grok).
- **Изолированные настройки**: Настройки сохраняются для каждого домена отдельно.
- **NoodleMagazine Enhancer**: Автоматически растягивает плеер на 100% и вырезает рекламу "Join Now".
- **Настройка горячих клавиш**: Переназначение любых кнопок через меню (F1).
