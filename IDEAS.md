# IDEAS — Копилка перспективных идей для MOSSAD

> 💡 **Назначение файла:**  
> Сюда складываются интересные технические идеи, фичи и предложения на будущее.  
> Скрипт и агент не сверяются с этим файлом в текущей работе. Когда у пользователя закончатся текущие идеи или возникнет желание что-то улучшить — мы просто откроем этот список и выберем лучшее.

---

## 🚀 Предложения и идеи "на потом"

1. **[Download / Range Fast-Hash] Предварительная проверка хеша по 64 КБ без скачивания видео**  
   *Суть:* Перед скачиванием 50 МБ видео делать `HEAD`-запрос и лёгкий `Range: bytes=0-65535`. Первые 64 КБ содержат сигнатуру и метаданные, уникальные для конкретного файла. Если совпал размер и первые 64 КБ — файл дубликат, 50 МБ трафика экономится на 100%.

2. **[UI / Badge] Индикатор базы на панели: бейдж количества записей**  
   *Суть:* Рядом с кнопкой «📥 База» или прямо на ней показывать маленькую цифру (например `18.2k`), меняющую цвет на зеленый при синхронизации.

3. **[Sync / Background Gist] Автоматический экспорт новых хешей в GitHub Gist раз в сутки/сессию**  
   *Суть:* Если пользователь скачал за день 50 новых видео, в конце сессии скрипт автоматически дельту (новые хеши) отправляет в GitHub Gist или репозиторий без ручных действий.

4. **[Media / Preview Modal] Быстрый предпросмотр оригинала при обнаружении дубликата**  
   *Суть:* В уведомлении «⚠️ Уже скачивался» добавить микро-кнопку «👁️ Показать оригинал», которая открывает локальный файл или ссылку на старый пост, чтобы сравнить два файла визуально.

5. **[Smart History / Cleaner] Поиск и удаление битых/несуществующих ссылок из базы**  
   *Суть:* Кнопка в настройках «Очистить базу от недоступных URL» для поддержания базы в идеальном состоянии.
