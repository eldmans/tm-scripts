## 🌐 Общие тудушки (для всех доменов)

- [ ] **[Срочно] [UI / TopBar] Кнопка обновления скрипта в самом верхнем поле и стрелка раскрытия панели крайней справа**  
  *Приоритет:* 2 (Срочно)  
  *Контекст:* В самом верхнем поле (плавающий TopBar) элементы управления должны быть расположены максимально эргономично.  
  *Требование:* 
  1. Значок «Обновить скрипт» (`🔄`) должен находиться в самом верхнем поле (TopBar).
  2. Стрелочки разворачивания/сворачивания панели (`▼` / `▲`) перенести в крайнее правое положение (максимально вправо, чтобы правее них ничего не было).

- [ ] **[UI / Окно настроек] Поддержка Drag & Drop (таскание мышью) и позиционирование под виджетом**  
  *Приоритет:* 5 (Обычный)  
  *Контекст:* Сейчас модальное окно настроек (`#mossad-hk-modal`) открывается статично по центру экрана (`top: 50%; left: 50%`) и его нельзя перетаскивать.  
  *Требование:*
  1. Окно настроек должно открываться не по центру экрана, а в продолжение основного виджета скрипта — непосредственно под ним, там, где он находится в текущий момент.
  2. Сделать окно настроек перетаскиваемым мышью (drag & drop) за шапку/заголовок (по аналогии с основным виджетом).

- [ ] **[UI / Окно настроек] Закладки (вкладки/табы) сверху: «Горячие клавиши» и «По умолчанию»**  
  *Приоритет:* 5 (Обычный)  
  *Контекст:* В окне настроек сейчас единым списком отображаются хоткеи и токен GitHub, без разделения по смысловым экранам.  
  *Требование:* Реализовать сверху окна переключение вкладок (табов, как в классических окнах настроек Windows):
  1. Вкладка 1: «Настройка горячих клавиш» (текущий редактор клавиш).
  2. Вкладка 2: «Данные по умолчанию» (настройки по умолчанию: круги видео `videoLoops`, задержка фото `slideshowDelay`, пауза после видео `delayAfterVideo`, с сохранением в общий конфиг/GitHub Gist для применения при открытии новых вкладок).

- [ ] **[UI / Нижняя строка панели] Большая шестерёнка `⚙` (без текста) и широкая кнопка с надписью «Перемотка»**  
  *Приоритет:* 5 (Обычный)  
  *Контекст:* В нижней строке панели кнопка настроек сейчас занимает много места текстом (`⚙ Настройки`), а кнопка перемотки на начало ленты узкая (`↺`).  
  *Требование:* 
  1. Убрать текст «Настройки», сделать компактную кнопку с большой шестерёнкой (`⚙`).
  2. За счёт освободившегося места увеличить кнопку перемотки и добавить понятную надпись: «↺ Перемотка».

- [ ] **[Download / pdAction +1] Защита от преждевременного перелистывания при обнаружении дубликата**  
  *Приоритет:* 5 (Обычный)  
  *Контекст:* Если включена настройка «После DL: +1» (`config.pdAction === 'up'`), при попытке скачивания файла, который уже был скачан ранее (сработал детектор дубликатов по хешу/URL и появилось предупреждение «Файл уже скачан»), скрипт всё равно перелистывал на следующий слайд.  
  *Требование:* Перелистывание (+1) или пост-действие (del) должно происходить **только тогда, когда файл действительно скачивается**. Если появилось предупреждение о дубликате — перелистывание останавливается и ждёт. Если пользователь нажимает скачать повторно (подтверждая скачивание дубликата за отведённое время) и файл начинает скачиваться — только тогда выполняется переход к следующему слайду.

- [ ] **[UI / Перенос кнопки «Сброс»] Убрать «Сброс» из нижней строки панели внутрь окна настроек**  
  *Приоритет:* 5 (Обычный)  
  *Контекст:* Сейчас кнопка «↺ Сброс» (сброс настроек и горячих клавиш) находится прямо в нижней строке виджета на виду.  
  *Требование:* Убрать кнопку сброса из главной панели и перенести её внутрь модального окна настроек (в безопасное место рядом с управлением конфигом).

- [ ] **[UI / Иконка скачивания] Замена дискеты (`💾`) на пиктограмму загрузки**  
  *Приоритет:* 5 (Обычный)  
  *Контекст:* Кнопка скачивания сейчас использует иконку дискеты `💾` («сохранить»).  
  *Требование:* Заменить дискету на более подходящую пиктограмму скачивания (например, `⭳`, `📥`, `⬇️` или векторную пиктограмму стрелки в лоток), символизирующую именно «Скачать».

- [ ] **[Database / Sync] Пересканирование локальной базы и синхронизация хешей с GitHub**  
  *Приоритет:* 5 (Обычный)  
  *Контекст:* Если файлы на диске были вручную перемещены, переименованы или скопированы — скрипт сканирует имеющуюся директорию, актуализирует хеши/пути и отправляет обновленную базу в репозиторий на GitHub для синхронизации между устройствами.

  *Приоритет:* 5 (Обычный)  
  *Контекст:* На видеоплеере Grok кнопка разворачивания видео имеет специфическую разметку с `aria-label="Expand video"` и иконкой Lucide:
  ```html
  <div class="absolute top-0 left-0 flex flex-row justify-end items-center w-full py-3 p-4 gap-2">
    <button class="inline-flex items-center justify-center gap-2 whitespace-now...d hover:text-white transition-opacity duration-300 opacity-0" data-slot="button" type="button" aria-label="Expand video">
      <svg class="lucide lucide-expand size-[20px]" xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
        <path d="m21 21-6-6m6 6v-4.8m0 4.8h-4.8"></path>
        <path d="M3 16.2V21m0 0h4.8M3 21l6-6"></path>
        <path d="M21 7.8V3m0 0h-4.8M21 3l-6 6"></path>
        <path d="M3 7.8V3m0 0h4.8M3 3l6 6"></path>
      </svg>
    </button>
  </div>
  ```

  1. Селектор `button[aria-label="Expand video"]` или кнопка с дочерним `svg.lucide-expand`.
  2. Проверка видимости/опасити и вызов программного клика через `triggerClick()` с серией попыток (100, 300, 500 мс).

## 🏁 Завершённые задачи из бэклога

- [x] **[FS] Автоматический Full Screen при переходе на новую страницу** *(v1.2.45, 2026-09-04)*  
  Единая общая настройка `autoFS` с чекбоксом `FS` в панели для всех доменов. Функция `triggerUniversalFullScreen()` с серией из 3 попыток (100, 300, 500 мс) срабатывает при смене слайда, переходе на новый URL и действии `pdAction: 'up'`. Поддерживает Grok, Pinterest и универсальный полноэкранный режим.

- [x] **[Звук / ScrollLock] Корректный Mute / Unmute в плеере Grok** *(v1.2.45, 2026-09-04)*  
  Перехват хоткея звука `config.hk.sound` (`ScrollLock`) на `grok.com`. Поиск DOM-кнопки звука плеера («Заглушить», «Включить звук», mute/unmute, sound) и программный клик по ней с анимацией нажатия без рассинхронизации интерфейса.

- [x] **[PageUp / Upscale] Повышение качества до 720p на Grok** *(v1.2.45, 2026-09-04)*  
  Обработчик хоткея `config.hk.upscale` (динамическая клавиша, по умолчанию `PageUp`). Двухшаговый регистронезависимый поиск (RU/EN): нажимает «Upscale» / «Повысить качество» (напрямую или через кнопку «три точки»), затем через тайминги 100/300/500 мс нажимает «Увеличить до 720p» / «Upscale to 720p».

- [x] **[Скачивание / 3-dots] Двухшаговое скачивание на Grok через меню** *(v1.2.45, 2026-09-04)*  
  Если прямой кнопки «Скачать» нет на панели, открывается кнопка «три точки» («Действия с постом»), и через тайминги 100/300/500 мс нажимается пункт «Скачать» / «Download».

- [x] **[Удаление / a.confirm] Автоподтверждение удаления на Grok** *(v1.2.45, 2026-09-04)*  
  При нажатии `Delete` и включенной опции `deleteAutoconfirm` серия из 3 попыток (100, 300, 500 мс) находит кнопку подтверждения («Удалить изображение» / «Удалить видео» / «Delete») и подтверждает удаление. Поддерживает открытие диалога через меню «три точки», если кнопка скрыта.

- [x] **[Удаление / hold post] Умное удержание позиции в ленте при удалении** *(v1.2.45, 2026-09-04)*  
  Скрипт вычисляет соседний пост из DOM-ссылок или очереди коллекции до удаления, а после подтверждения удаления переходит на сохранённый URL соседнего поста, предотвращая сброс в конец ленты Grok.

- [x] **[Core / retryAction] Универсальный хелпер попыток** *(v1.2.45, 2026-09-04)*  
  Вынесен универсальный хелпер `retryAction(fn, [100, 300, 500])` и `triggerClick` в `src/core/utils.js`.
